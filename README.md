# ELO301 Firmware Templates

This repository provides firmware templates for the **ELO301** class. They
serve as starting points for laboratory assignments and embedded software
development with STM32 microcontrollers and STM32CubeIDE. Students can use
the template corresponding to their board and extend it for each assignment.

## Templates

| Folder | Purpose |
| --- | --- |
| [Template](Template/) | Template for the **NUCLEO-L452RE**, based on the STM32L452RE microcontroller. Includes the course firmware interfaces and an I2C temperature sensor emulator supplied as a binary library. |
| [Template_ELOBoard](Template_ELOBoard/) | Template for the course's **ELOBoard**, based on the STM32G0B1CBT6 microcontroller. Provides the firmware starting point for assignments using that board. |
